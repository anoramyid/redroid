# Contributing Guide

## Commit Message Format
Use the following format: `type(scope): message`
- `feat`: New feature.
- `fix`: Bug fix.
- `docs`: Documentation changes.
- `chore`: Maintenance tasks (e.g., backups).
- `refactor`: Code refactoring.

## Workflow
1. Implement changes in code or scripts.
2. Update `memory.md` via AI MEMORY UPDATE.
3. Commit and push your changes.
4. For large assets (backups), use the provided release scripts instead of Git.
