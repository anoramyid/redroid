# Contributing Guide

## Commit Format
Gunakan format: `type(scope): message`
- `feat`: Fitur baru.
- `fix`: Perbaikan bug.
- `docs`: Perubahan dokumentasi.
- `chore`: Tugas pemeliharaan (seperti backup).

## Workflow
1. Lakukan perubahan pada kode/script.
2. Update `memory.md` via AI MEMORY UPDATE.
3. Commit dan Push.
